## 수정 후보 (추천 순)

1. **화면/앱 숨김 시 자동 중지**: `document.visibilitychange` -> hidden이면 기본 모드는 `stopSession()`, 듀얼은 엔진만 닫는다.
2. **유휴 자동 중지**: 예를 들어 2분 동안 발화가 없으면 연결을 닫는다. 재시작에는 1~2초 연결 대기가 생긴다.
3. **듀얼은 첫 발화 때 엔진 연결**: 페어링만으로는 과금이 시작되지 않게 한다. 대신 첫 발화가 1~2초 늦어진다.
4. **기본 모드 상대 방향 지연 연결**: 대기 비용이 절반으로 준다. 대신 상대의 첫 발화가 늦어진다.
5. (진단용) 세션 열림/닫힘을 서버 로그에 남기는 클라이언트 보고를 추가해 실제 과금 시간을 집계한다.
